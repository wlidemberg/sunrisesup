Execute o ciclo padrão do FrontCore para a tarefa solicitada:
1. Analise o escopo e apresente sugestões técnicas (bibliotecas/banco) para aprovação.
2. Estruture a documentação em docs/requisitos.md e docs/design-system.md.
3. Crie a branch em português seguindo o padrão funcionalidade/<nome>.
4. Escreva os testes unitários (Vitest) antes de implementar o código React + Tailwind.
5. Execute os testes e verificações estáticas no terminal integrado.
6. Apresente o relatório de testes e aguarde aprovação para o commit semântico.
